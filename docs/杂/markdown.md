# Markdown 五分钟入门

> 一份简明的 Markdown 语法速查手册，帮助你快速掌握常用语法。

## 标题（Headers）
```markdown
# H1 Header
## H2 Header
### H3 Header
#### H4 Header
##### H5 Header
###### H6 Header
```

## 文本格式（Text formatting）
```markdown
**bold text**
*italic text*
***bold and italic***
~~strikethrough~~
`inline code`
```

## 链接和图片（Links and images）
```markdown
[Link text](https://example.com)
[Link with title](https://example.com "Hover title")
![Alt text](image.jpg)
![Image with title](image.jpg "Image title")
```

## 列表（Lists）
```markdown
Unordered:
- Item 1
- Item 2
  - Nested item

Ordered:
1. First item
2. Second item
3. Third item
```

## 引用（Blockquotes）
```markdown
> This is a blockquote
> Multiple lines
>> Nested quote
```

## 代码块（Code blocks）
````markdown
```javascript
function hello() {
  console.log("Hello, world!");
}
```
````

## 表格（Tables）
```markdown
| Header 1 | Header 2 | Header 3 |
|----------|----------|----------|
| Row 1    | Data     | Data     |
| Row 2    | Data     | Data     |
```

## 分隔线（Horizontal rule）
```markdown
---
or
***
or
___
```

## 任务列表（Task lists）
```markdown
- [x] Completed task
- [ ] Incomplete task
- [ ] Another task
```

## 转义字符（Escaping characters）
```markdown
Use backslash to escape: \* \_ \# \`
```

## 换行（Line breaks）
```markdown
End a line with two spaces  
to create a line break.

Or use a blank line for a new paragraph.
```
