# list、tuple、dict、set 四种数据类型的定义与异同

<!--more-->

## list

list 是一种有序的集合，可以随时添加和删除其中的元素。

```python
# 声明
classmates = ['Mi', 'Bo', 'Tr']
# 长度
len(classmates)
# 索引
classmates[0]
# 倒数第一个索引
classmates[-1]
# 追加
classmates.append('Ad')
# 插入
classmates.insert(1, 'Ja')
# 删除末尾
classmates.pop()
# 删除指定位置
classmates.pop(1)
# list的元素可以为其他的数据结构
L = ['Ad', 123, ['ad', 'ds']]
```

## tuple

tuple 是**不可修改**的 list。一旦初始化后，就不能修改。

因为**不可修改**，所以代码更为安全。

```python
# 声明
classmates = ('Mi', 'Bo', 'Tr')
# 因为括号()既可以表示tuple，又可以表示数学公式中的小括号，
# 所以Python规定：只有1个元素的tuple定义时必须加一个逗号","来消除歧义
t = (1)     # 这不是tuple，是整数1
t = (1,)    # 这才是只有一个元素的tuple
```

另外，由于特殊的结构，还存在一种"可变"的tuple。

```python
# "可变"的tuple
t = ("Ad", 123, ['sad', 'asda'])
```

这是因为 tuple 内含的 list 是可变的，而 tuple 本身的指向和结构并没有发生改变。

## dict

dict 是 dictionary（字典）的缩写，在其他语言中也称为 map 或 hash map。它基于哈希表实现，使用键-值（key-value）方式存储数据，查找速度极快。

```python
# 声明
d = {'Mi': 95, 'Bo': 85, 'Tr': 75}
```

### dict 和 list 查找速度对比

**list**：

list 按顺序逐个遍历元素进行查找，因此列表越大，查找越慢（线性时间复杂度 O(n)）。

**dict**：

给定一个 key 值，通过哈希函数计算出 value 的存储位置。例如对于键 "Mi"，dict 通过哈希函数直接计算出对应的存储地址，即可直接取出 value，查找时间与字典大小无关。

```python
# 初始化后赋值
d['Mi'] = 97
# Key不存在会报错
# 判断key是否存在
'Mi' in d
# 通过get方法，如果key不存在，返回指定value
d.get('Mi', -1)
# 删除一个key
d.pop('Bo')
```

**dict 是一种空间换时间的方法。**

**dict 的 key 值是不可变对象。**

因为 key 的哈希值决定了 value 的存储位置，如果 key 发生变化，哈希值也会改变，导致 dict 内部结构混乱。list 是可变类型，因此不能作为 dict 的 key。

## set

set 是无序无重复的元素集合。

**创建一个 set，可以传入一个 list 作为输入集合，也可以直接使用花括号语法。**

```python
# 声明
s = set([1, 2, 3, 3])
# 重复元素会被自动去除
# 结果为 {1, 2, 3}
# 添加元素
s.add(4)
# 删除元素
s.remove(3)
# 支持交集、并集等集合运算
s1 = set([1, 2, 3])
s2 = set([2, 3, 4])
# s1 & s2 结果为 {2, 3}
# s1 | s2 结果为 {1, 2, 3, 4}
```

## 小结

**list** 是有序可变集合，使用中括号：

```python
lst = ['ad', 123, False]
```

**tuple** 是有序不可变集合，使用小括号：

```python
tup = ('ada', 1231, lst, ['dsa', 'dasda'])
```

**dict** 是 key-value 结构的有序集合（Python 3.7+ 保证插入顺序），使用花括号：

```python
d = {'Ad': 96, 'Mi': 97}
```

**set** 是无序无重复的元素集合：

```python
s = set(['ads', 'dasd', 123])
```
