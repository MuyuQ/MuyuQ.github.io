## 1. SQLAlchemy 中 filter() 与 filter_by() 的区别

```python
Wish.query.filter(Wish.launched == False)
Wish.query.filter_by(uid=uid, launched=False)
# 一个是条件表达式，一个是关键字参数
```

## 2. 继承第三方库的某个类

```python
class Query(BaseQuery):
    def filter_by(self, **kwargs):
        # kwargs是字典
        if 'status' not in kwargs.keys():
            kwargs['status'] = 1
        # 重写完成后，调用基类方法
        return super(Query, self).filter_by(**kwargs)

# 在Flask-SQLAlchemy中提供了继承基类的接口
db = SQLAlchemy(query_class=Query)
```

## 3. group_by 查询与 ONLY_FULL_GROUP_BY 模式

```python
@classmethod
def recent(cls):
    # 链式调用
    recent_gift = Gift.query.filter_by(launched=False).group_by(
        Gift.isbn).order_by(Gift.create_time).limit(
        current_app.config['RECENT_BOOK_COUNT']).distinct()
    return recent_gift
```

MySQL 5.7+ 默认在 sql_mode 中开启了 ONLY_FULL_GROUP_BY，该模式不允许 SELECT 列表里出现既不在 GROUP BY 中、也没有被聚合函数包裹的列（与 GROUP BY 列存在函数依赖的除外，例如按主键分组）。上面这条查询只 GROUP BY 了 Gift.isbn，SELECT 的却是整个 Gift 实体的所有字段，违反了这一要求，因此会报 1055 错误。

如果只是想让这条查询正常执行，可以从 sql_mode 中去掉 ONLY_FULL_GROUP_BY：

```mysql
SET GLOBAL sql_mode=(SELECT REPLACE(@@sql_mode,'ONLY_FULL_GROUP_BY',''));
```

## 5. session.query 查询

```python
@classmethod
def get_wish_count(cls, isbn_list):
    # 根据传入的一组isbn，到Wish表中检索出对应的礼物，并计算出每个礼物的心愿数量
    # db.session
    # mysql in查询
    return db.session.query(func.count(Wish.id), Wish.isbn).filter(
        Wish.launched == False,
        Wish.isbn.in_(isbn_list),
        Wish.status == 1).group_by(Wish.isbn).all()
```

这种写法非常 Pythonic，值得多看、多学、多写。

`db.session.query()` 中传入的参数决定了根据检索条件返回的数据列。

## 6. 避免循环导入

当我们 import 一个文件时，Python 会首先去查找这个文件之前是否被 import 过。如果这个文件之前已经被 import 过，就不会重新再 import 一次。

因此，如果 A 模块代码里 import 了 B 模块，并且 B 模块里又 import 了 A 模块，Python 的执行顺序会变成这样：

1. 开始执行模块 A
2. 当 A 执行到 `import B` 的地方，停止执行 A 模块后面的代码，转而开始执行 B 模块的代码
3. 当 B 模块从头执行到 `import A` 的地方时，Python 此时并不会回过头去接着执行 A 剩余的代码，而是将 A 模块在中断前已经初始化的属性全部加载到 B 模块中

以下是两种避免循环导入的常用方法：

**方法一：在函数内部使用 import（延迟导入）**

这种方式会带来一定的性能开销，但可以有效避免循环导入问题。

```python
def func():
    from time import sleep
```

**方法二：将引起循环导入的变量放到导入模块 import 代码之前**

```python
src.user = None
from core import src
```

## 7. 捕获 KeyboardInterrupt 异常

运行命令行程序期间，如果用户想终止程序，一般会按 Ctrl+C，此时程序会抛出 `KeyboardInterrupt` 异常。

可以通过这一机制来实现我们想要的功能：

```python
import time
print('按下回车开始')
try:
    input('')
    starttime = time.time()
    print('开始')
    while True:
        print('计时', round(time.time() - starttime))
        time.sleep(1)
except KeyboardInterrupt:
    print('结束')
    print('总计耗时:', round(time.time() - starttime))
```

通过抛出异常来终止 `while` 循环，从而实现计时器功能。
